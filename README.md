# BandSync

One click for the whole band, over Wi-Fi.

- `bandsync-app/` — Android app: any member hosts, or joins; per-stem local mix; locked-screen playback.
- `bandsync-host/` — Windows PC host: bridges DAW transport (MIDI Clock) to the phones, so pressing play in Cubase drives every phone.

See each folder's README for setup.
